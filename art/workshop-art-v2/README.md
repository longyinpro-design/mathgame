## 接入边界

- 本批是**源美术母版**。尚未切片、校准脚底及转轴、统一像素网格、制作连续动作帧，也未完成 Godot 导入或实窗验收。不能把本清单当作 GW02～18 已可玩或运行时资源封版。
- 所有透明母版实测含 alpha；总机和通用道具两张源图最高 alpha 为 254，实体可能轻微透底。上架前需在浅色、深色及实际场景中逐件验边，必要时定向重绘。
- 通用道具图左上生成物实测为压机形态，**不是**报时架；报时铃架使用 `dock-moving-parts-source-v1.png` 左件。该件铃舌已画进铃内，若要逐帧敲击须再拆开或重绘。总机图仅有拆件造型，臂的关节、装卸锚点与运行顺序由场景定义。
- 状态特效四件彼此独立，不是可等分动画；蒸汽不得盖住数字与可操作区。信号亮灭、货物归属、准确数量、时刻格、船期、接收记录与题目由引擎绘制和判定。
- 源图中的船为空货船；船舱的三处接收位置与载货动画尚需在场景中配置。新场景的交互热区、地面接触、缩放和遮挡需要随各关实现验收。

本批完成的是首批明确列出的**剩余美术母版覆盖**，不是整章可直接使用的精灵、动画和 TileSet 包。
