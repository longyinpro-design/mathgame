## 使用边界与后续整备

- 本批是原始美术母版：尚未切片、统一像素网格、校准脚底/转轴/取放挂点或经过 Godot 导入与实窗验收。四个角色姿态不是连续动画，不能等分后直接当动画序列。
- 空托盘由引擎绘制准确槽位，空模具由引擎绘制孔位；数量、时间格、刻度、指针、货物归属及状态均由引擎维护。背景砖缝和装饰齿轮不承载数学规则。
- 码头图上半部建筑装饰较密，中央与下半部可用于演出；升降台应先匹配井道宽度，不能凭源图透视直接推导运动坐标。场景实际比例见清单，不能假定生成尺寸等于提示词尺寸。
- 透明通道按原样保存，清单记录 alpha 分布。部分源图最高 alpha 为 254，存在轻微实体透光；未完成浅色/深色背景上的逐部件边缘验收。不能把存在透明像素等同于运行时精灵质量通过。
- 压机等在本批中仍为整体造型源图；压头、摇杆、铃舌、车轮等需要动画的部分后续仍须独立拆件或定向重绘。
- 首张码头提示词来自已确认的章间方向，读取完整设计后复核为可用基础稿；装配间、嗒嗒和机关提示词绑定详细设计。码头偏暖金与青绿，后续合场景时可进一步统一铁蓝/奶油白/铜橙比重。
- 本批没有覆盖旧报时廊、屋顶修理街、总机船坞、两位居民、两位首领和全章特效。后续按设计先校准首个切片，再推进这些资源。

预览：打开 `index.html`，可切换浅色、深色与棋盘背景检查透明素材。页面使用原文件，不修改图片像素。
