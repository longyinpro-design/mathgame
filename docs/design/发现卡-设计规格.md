# 发现卡 · 设计规格

日期：2026-09-22。目标年级：**三年级**（已锁定）。状态：P0-A 已实现并通过无头校验；支架部分为纸面原型。

配套文档：[数学学习闭环优化方案](数学学习闭环优化方案.md)（问题诊断与优先级）、[discovery_catalog.gd](../../scripts/content/discovery_catalog.gd)（文案源）。

---

## 1. Purpose

把玩家在关卡里**已经做对**的动作，在通关那一刻命名成一个能带走的方法。

它不教新东西，也不检查任何东西。它只做一件事：孩子刚才靠直觉做成的事，现在有了名字。没有这一步，「做对了」和「学会了」之间那道缝永远合不上。

## 2. Player experience goal

通关的爽感之后紧接一句确认感——「我刚才那个办法原来有名字」。不打断、不考试、不要求操作。

失败的样子是：孩子记住了名字，但换一关就想不到用它（见第 6 节信号 E）。

## 3. 结构

三行，写在同一块横幅的下半段：

| 行 | 内容 | 例子（FL02） |
| --- | --- | --- |
| 1 | 方法名 | 倒着走 |
| 2 | 一句话解释 | 不知道开头是几，就从最后的8、8、8往回走，每步做相反的事。 |
| 3 | 还在哪儿用过 | 「倒着走」还会在后面的机关里用到。 |

第 1 行的措辞是**动作**，不是术语。`reverse_state` 写成「倒着走」，`parity_invariant` 写成「只看单双数」——术语留给教师版，孩子拿到的是能照着做的动作。

### 输入 / 输出

- **输入**：`definition.id`、`definition.concept_ids`、`progress.completed_levels`、`catalog.levels`
- **输出**：`discovery_catalog.card(id)` 给第 1、2 行；`cross_reference(...)` 给第 3 行
- **不读取**：提示层级、撤销次数、用时。发现卡是关卡属性，不是玩家评价，所以同一关每个人看到同一张卡。

## 4. 边界情况

| 情况 | 处理 |
| --- | --- |
| 该关没有卡 | 横幅保持 172 高度，下半段完全不出现，布局与旧版逐像素一致 |
| 首通 | 第 1 行标题写「你发现了一个办法」 |
| 重玩 | 标题改「这一关用的办法」。卡片内容照旧出现——学习靠复现，重复不是噪音 |
| 用过提示才通关 | 照常显示。卡住的孩子更需要命名，这里不做任何惩罚性标记 |
| 该概念在别的已通关关卡出现过 | 第 3 行点名那一关：「还能用在：借粮之前的三座仓」 |
| 只在未通关的关卡出现过 | 第 3 行只说「还会在后面的机关里用到」，不点名，避免剧透顺序 |
| 只出现过一次 | 如实说「这是你第一次用到它」，**不编造预告** |
| 一关有两个概念 | 只命名一个（最核心的那个），另一个留到它当主概念的关卡。一次教一个 |

最后两条是有代价的诚实：当前 30 个概念里 **23 个只出现在一关**，所以样板里 8 张卡有 5 张的第 3 行会落在「第一次用到」。这不是文案的毛病，是复现不足的直接暴露——铺量前要先决定 P2-E 补到什么程度。

## 5. 文案约束（写新卡时照此）

1. 名字三到六个字，动词开头；
2. 解释不超过 40 字、最多两句；超过会折行压住第 3 行；
3. 不出现坐标、组合数、`±` 和英文缩写，不出现「奇偶」「穷尽」「不变式」「下界」这类术语；
4. 主概念必须是该关 `concept_ids` 里真实存在的一项；
5. **解释里出现的每个数字都要能在该关 `params` 或规则里核对出来。**

第 5 条踩过坑：FL04 的合重是 **29/35/30**（三架共 47），而 `content_catalog.gd` 的 `LEGACY_RESULT_PARAMS` 里写着 11/13/12——那是旧档兼容值。照着它写进卡片，孩子按卡片算会算不出三架灯的重量。所以 `tests/forest/discovery_test.gd` 里专门有一条断言盯着这三个数不许出现。

## 6. 失败信号

先定义坏掉长什么样，再去测。

| 信号 | 含义 | 处置 |
| --- | --- | --- |
| A · 被秒关（平均停留 < 3 秒） | 文案没信息量，或它在打断心流 | 改为默认折叠，进手记回看 |
| B · 用过提示的孩子，下一关同概念仍然用提示 | 发现卡只命名，没有支架 | 说明 P0-B 不能省，必须做 |
| C · 手记页打开率接近 0 | 容器没价值 | 砍掉，内容并进发现卡 |
| D · 换情境时孩子不提旧办法 | 命名没转化为迁移 | 最坏信号，回头重做文案，别加新系统 |
| E · 能背出名字但解不出变式 | 命名成了标签收集 | 去掉名字的术语感，改成更动作化的短语 |

## 7. Tuning levers

| 杠杆 | 当前值 | 依据 | 错了会怎样 |
| --- | --- | --- | --- |
| 横幅高度 | 有卡 312 / 无卡 172 | 三行文案 + 回指各占一行 | 需要第四行时整块重排 |
| 解释字数上限 | 40 字 [PLACEHOLDER] | 940px 版面在 22 号字下的一行容量 | 超了折行压住回指 |
| 停留时长 | 15–25 秒 [PLACEHOLDER] | `策划案-v1.md` 的单关 4–8 分钟目标 | 未实测；超过 40 秒说明打断心流 |
| 第 3 行点名上限 | 2 关 | 版面宽度 | `cargo_planning` 有 3 关，需要时会截断 |

## 8. 落地位置

| 文件 | 作用 |
| --- | --- |
| `scripts/content/discovery_catalog.gd` | 唯一文案源 + 回指逻辑 + `check()` 校验 |
| `scripts/ui/forest_release.gd` | `draw_completion()` 决定横幅高度；`draw_discovery()` 画下半段 |
| `tests/forest/discovery_test.gd` | 55 条内容校验，含 4 条反向用例 |
| `tests/forest/assets_test.gd` | 字体覆盖扫描名单加入 `discovery_catalog.gd`（见下） |

### 字体覆盖

`assets_test.gd` 会把名单里每个脚本的**所有** CJK 字符（含注释）抠出来，逐个查游戏字体
`ZCOOLKuaiLe-Regular.ttf` 有没有这个字形。卡片的名字与解释是直接画在横幅上的，
理应和 `forest_release.gd` 一样过这道检查——但它原先不在名单里，缺字形的卡片会在实机上
显示成方块而测试毫无察觉。本次已把 `discovery_catalog.gd` 加进名单。

实测：字体 7053 个码位，覆盖脚本中全部 781 种汉字，**缺字形 0 个**。

### 运行前置

首次在干净工作树上跑这条链路前，必须先 `godot --headless --import --path .`。
`.godot/` 是导入缓存，不随代码走；它不存在时 `preload` 贴图的脚本会解析失败，
`assets_test.gd` 会挂到超时并报 "Godot test execution timeout"，症状看起来像
「只有资源这一个测试坏了」，实际与代码无关。

**撤掉的东西**：`draw_completion()` 里原本按 `family` 硬写的三条「为什么」（对应 FL08/FL10/FL13），用的是审稿人语言（`(1,0)` 坐标、`C(4,2)`、「3 个对象」）。三条全部进卡片换成了孩子能读的说法，硬编码整体删除——不留两份要同步的文案。测试里有一条断言盯着这三个家族必须都有卡，防止哪一关的「为什么」凭空消失。

**关于 `thinking_contract.insight`**：这一层**不读** `insight`。insight 是写给审稿人的设计意图，含 `C(4,2)=6`、坐标、「互斥且穷尽」这类语言。两者说的是同一件事，读的人不同，所以分开维护，不共用一份文案。

## 9. 首版覆盖范围

8 关，覆盖 8 个概念：

| 关卡 | 概念 | 名字 | 解释 |
| --- | --- | --- | --- |
| FL02 石灵的三门借光 | `reverse_state` | 倒着走 | 不知道开头是几，就从最后的8、8、8往回走，每步做相反的事。 |
| FL04 三架灯的秘密 | `equal_substitution` | 一样的换着比 | 三架灯每架都称了两次。三条合重加起来再分成两半，就是三架一共多重。 |
| FL08 不会漏信的分邮袋 | `exhaustive_partition` | 一袋一袋数 | 按第一次往右的高度分袋子。每袋该装几条是定死的：6、3、1，合起来10条。 |
| FL10 互不碰面的两封信 | `joint_constraints` | 先分两拨 | 每封信不是先往右就是先往上。同一拨的两封会撞在同一个路口，所以最多两封。 |
| FL12 守门人的三种回应 | `strategy_blocks` | 凑够一组 | 每次能拿1到3颗，就凑够4颗当一组。对手拿几颗，你补到4颗。 |
| FL13 两趟足够吗 | `lower_bound` | 先算最少几趟 | 一趟只有一个篮子能到顶，最多送两件。三件货至少要两趟。 |
| FL14 偶数也到不了的石径 | `parity_invariant` | 只看单双数 | 每步加2或减2，只会停在双数上；要停在9，得先把一步换成加1或减1。 |
| FL16 借一道墙的花圃 | `area_perimeter` | 围一围比一比 | 篱笆一样长，围出的地不一定一样大。把每种宽都试一遍，3乘6最大。 |

比原计划的 6 关多两级，理由是 FL08/FL10/FL13 本来就有硬编码的洞察行要拆，留着会和孩子语言的卡片并排显示，两种语气挨在一起比多写两关贵。
