# MK05 四张被雨打湿的货签 — v1 样板契约

2026-09-20。第二岛「千灯集市」第三幕第一关，`docs/production/market_chapter.md` 第 131–137 行的题面与第 320 行的节奏说明是唯一的题目来源。本文件只登记 MK05 自己的事实；`level_host.gd`、`chapter_catalog.gd`、`art/market-kit-v1/manifest.json` 等共用文件一律未改。唯一的共用改动是打磨轮把纸面几何提炼进 `kit_world.gd`（新增 `PAPER_TOP`/`PAPER_TALL` 与 `paper_rect()`，MK04 与 MK05 共用同一份 `receipt_blank` 锚点算法）。

- 题目：灯芯街夜里下过雨，四只箱子（布、油、铃、纸）与四个去处（育苗铺、面包铺、桥头、邮亭）本来一一对应，货签上的去处被冲糊了，四家铺子的订单上只剩三句话读得清。玩家把柜台上四张货签按上订单板，一次配对完成交货；**不逐箱开箱，不靠点击揭示箱里是什么**。
- 数学真值：解唯一。`布去育苗铺`、`纸去邮亭` 两句直接钉死两家，`面包铺不收铃` 把铜铃挤到桥头，剩下的灯油归面包铺，即 assign `[面包铺=油, 育苗铺=布, 桥头=铃, 邮亭=纸] = [1,0,2,3]`。三句话一条都不能少：无头检查里逐条抹掉后剩下的约束分别放出 4、4、2 种配法（24 种一一对应全枚举）。桥头的订单被冲得最干净，它那一格只能靠排除法得到——这就是本关要教的那一步。
- 每件东西只有一个归属：`assign[去处] = 货签编号`（-1 表示还空着），一张货签不能同时按在两家。板上计数、手里是谁、哪家还空着全部由 `mk05_rules.gd` 现算，画面与提示都不另存计数。同一张签按两处既过不了 `validate()`，也过不了 `solved()`：即使三句话都读得通，这种自相矛盾的板子也绝不会放进交货演出。
- 交货先入账再演出：`advance()` 把 `stage="delivery"` 与板面一起落盘，动画结束才写 `complete`。保存失败或中途退出不会发布幻影回执，重载从同一演出继续。撤销快照（`{"assign":[…],"hand":…}`）只存在内存里，不写档。
- 入账时机区分「手感」与「决策」：点货签拿在手里（含换手里那张、放回柜台）走 `commit(next, history)`，**不占撤销步数**；按下某一家与从某一家取回走 `place()`，各记一步撤销。「重摆 · 全部取回」也是记一步的决策，且保留已经读过的提示数。
- 缺口只说事实，不判对错：未配齐就点「验货交货」，台词位逐条点名是哪一句留下的话被摆坏了——`订单板上「面包铺」写着「不收 铜铃」：铜铃正按在那儿。`；引号里那半句直接取 `Rules.KEPT[去处]`，也就是玩家抬头在那家门口那块残句牌上看见的一串字，一次只报第一条，两条以上补一句「还有 N 处没有归位」。空着的格子另报「订单板上还有 N 家没按货签：…」。任何情况下都不出现「答案错误」。无头检查把三条线索的 `kept` 逐条对回 `KEPT`，实窗再按整串文案硬比一次拒绝理由，措辞与牌面从此绑在一起。
- 演出用 `carry_plan()` 一处算出四只箱子的脚点：按去处从左到右错开 0.12 起步，各自沿平滑曲线抬到自家门口，途中按相位起落；在飞名单与「已按上但还没落位」的名单由每件货物自己的相位算出（`in_flight()`），没有沿用基类整段一刀切的 `hide_while_moving()`，免得后起飞的那只凭空消失。
- 完成后的回执由 `extra()` 现画：按玩家实际按下的格子复述四对「谁收谁」，并明确写下面包铺那张已经确认、十根灯芯那一单明天直接去领——这正是 MK06 的起点，MK06 里不需要重新接这张订单。
- 短节奏：三句开场白（玩家自己点「继续听他们说」推进）→ `approach` 镜头 1.5 秒走近 → `ready` 一句讲解 → 开放配对 → `delivery` 3.6 秒 → 回执。提示 3 档（一家一箱 / 先按读得清的两句 / 演示排除那一步），无惩罚、无自动摆放、无高亮答案、失败不重放。设计意图是 MK04 两道重逻辑之后的换气关，不包装成难题。
- 美术：底景 `lantern-street-stage-v1.png`，四家铺子取 `scenes[street].stations` 的 `stall_left / stall_midleft / stall_midright / stall_right`（与 `Rules.PLACES` 同序），`stall_middle` 留给「订单板 · 三句留下的话」的牌头，`counter` 摊四张货签并站扣扣；货签与订单纸面是 `receipt_blank`，货物图样是 `cloth_bolt / oil_bottle / brass_bell / paper_roll`。`anchor_px` 按裁剪图像素计，`origin = 脚点 − anchor_px × scale`，缩放只乘一次。雨痕、糊开的墨迹、店名与「收 布卷」那类残句全部由引擎绘制，不使用烘焙文本。manifest 里没有缺图，未新裁任何美术。
- 文本：所有中文 `Label` 都不依赖自动换行——开场白与提示里的 `\n` 是手写的，目标句一行、台词一行（798 像素宽），状态行 `板上 4/4 · 手里：布卷` 压在 300 像素框内；关卡名用「四张货签」四字，保证 394 像素的木牌装得下。街面上的名字与残句走 `plaque()`/`words()`，牌面上的字集中在世界层三个 getter 里拼（`board_head_plate()`、`counter_plate()`、`name_plate(去处,货签)`）：柜台那块牌跟着摊着的签数从「柜台 · 4 张货签」一路少到「柜台」（四张全按上板时柜台上没有一张纸，不许写「0 张货签」），门口那块牌没收货只写店名、收了货跟着写「× × · 收 × ×」，实窗把这 4 种店名牌、20 种门口牌与柜台牌的 5 档每一档全部量一遍宽度，不再抄一份文案去量。
- 交互：点货签拿起来、点一家铺子的订单按下、点已按好的格子取回，手里有签时点已按好的那一格是把原来那张换下来、让它回柜台（台词位与热点提示都写「取回或换下」，两种情况分开措辞）；键盘 1–4 拿起四张签、Q/W/E/R 按面包铺/育苗铺/桥头/邮亭、Space 验货交货、Z 撤销、H 请扣扣提醒、Esc 暂停演出。热点就是画出来的那面纸：`label_rect()`/`card_rect()` 走 `kit_world.paper_rect(脚点,宽)`，按 `receipt_blank` 237×316、anchor (118.5, 308) 算出纸尖到纸尾（76 宽的货签 76×101、84 宽的订单 84×112），而不是基类那个正方 `target()`——正方框比纸面矮 25 像素，玩家照着纸尖去点会落空；拿在手里的那一张整张抬 22 像素，热点跟着抬。全部 ≥48 逻辑像素；`puzzle` 镜头缩放 1.10、偏移 −64/−43 之后，八个热点仍完整落在台词框（y>166）与按钮排（y<646）之间，这两条是无头检查项，「热点盖住整面纸」与「抬起来的那张仍点得着」由实窗按 manifest 锚点独立复算一次（1280×720 与 960×540 各一次）。
- 入口 `game/market_mk05.tscn`，或双击 `启动千灯集市MK05样板.command`。独立存档 `user://profiles/market-mk05-1/save-v1.json`，schema 由 `mk05_rules.gd` 的 `validate()` 把关：别人的 sample、未知阶段、越界或重复的货签编号、`float` 板面、缺字段、没动过签却带着已按好的板、手里与板上是同一张、提示数越界、未完成却写成 `delivery/complete` 一律拒读并保留原文件。`configure()` 只在路径为空时填默认值，试玩注入的 `/tmp` 路径优先。
- 关卡关系：航图里 MK04 之后解锁，`chapter_progress.gd` 靠读本关存档的 `stage=="complete"` 点亮灯火，本关不写进度文件。从航图进来由宿主给「返回千灯航图」；独立启动或由上一关递条子进来时，完成后自己给一条「回千灯航图」。**本关不做跨关跳场景**，衔接只写在回执文案里（去 MK06 由航图承担）。
- 验证：`python3 tests/market/run_checks.py mk05` → `MK05 mk05_test.gd: 130/130 PASS`、`MK05 mk05_playtest.gd: 149/149 PASS`，`verification.json` 里 `status: PASS`、`source_stable_during_run: true`，输出零 `ERROR:` / `SCRIPT ERROR`。无头侧含 625 个板面状态的唯一性扫描、24 种一一对应与缺口清单的一致性、约 25 项坏档拒读、存档失败注入与重试、真实场景从开场白到回执的全流程、`snapshot()`/`cleared_state()` 与章节目录一致性，以及三条线索的 `kept` 逐一等于那家门口残句牌原文；实窗侧在 1280×720 与 960×540 各走一遍键盘与鼠标两条路径，除原有的宽度/遮挡/断行/1×1 截图之外，新增「四张货签与四张订单的热点盖住按 manifest 锚点独立算出的整面纸」「热点跟着手上的那一张抬 22 像素」「四家 × 五种牌面文案与柜台牌五档全部装得下」「拒绝理由整串文案与牌面原文硬比」，截图落在 `docs/playtest/market-mk05-labels/`（`small-` 前缀是 960×540 那一遍）。
- 已知限制：雨糊的去处是画出来的墨迹，不是可读文本，所以「这张签写的到底是哪儿」这类误读只能靠玩家自己发现；本关不校验儿童真实理解度，也没有触屏与音频；扣扣仍是抱货／挥手两个离散姿态，不是连续动画帧；回执是引擎文字面板，manifest 里没有对应的成品单据图。
