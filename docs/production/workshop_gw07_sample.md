# GW07 · 检修前，先留好位置

2026-09-24。按 [GW01契约](workshop_gw01_sample.md) 同一套三年级奥数难度与制作原则实现。核心思考是「有限空间、提前留空」：已知冷却机有一段检修停机，就得在它前后留好暂存位。不是原章节里的基础分组轻关，也不声称已通过儿童难度实测。

## 可玩契约

A、B、C、D 依次经过压机和冷却机，压制各1拍、冷却各2拍。两机一次各一件；中间仅一个暂存位，先来先冷却。冷却机在第4～5拍检修，工序不能与检修区间重叠，也不能暂停后接着冷却。压机不能当仓库。要求最迟第11拍完成全部。

第一件最早1–3冷却；检修前放不下第二个完整2拍冷却，所以后三件最早5–7、7–9、9–11，第11拍就是下限。一套压制计划为 0–1、1–2、4–5、6–7；冷却为 1–3、5–7、7–9、9–11。B 要到第5拍才进机，可它要是早早压完占着暂存位，后面两件就没位置了。

- 开工拍由玩家设定，完成时刻、暂存位占用与检修冲突全部由规则现算；检修格从开局固定显示。
- 接受所有达到11拍且不溢位的方案，不锁示例压制时刻。
- 四档主动提示依次为：先看检修哪段不能用 → 检修前最多塞一件 → 倒看B何时取走、C何时入位 → 示例双轨。默认不显示解，也不自动填关键中间量。

玩家同时安排压制和冷却的开工拍。试运行会跑到第一处说不通的地方才停，并说清是哪件货、哪一拍；任何排法都进得了演出，没有「必须先排满」的门槛。

## 操作与存档

- 启动 `启动齿轮工坊GW07样板.command` 或 `game/workshop_gw07.tscn`。
- 鼠标完整可玩；↑/↓（或点压制带/冷却带）换带，←/→换货，Q提前1拍、W推后1拍，点某一格直接选中它，Z撤销，X确认退回草稿，H主动提示，Space试运行。保留Tab/Enter焦点操作。
- 重排、重玩有确认。撤销与重排保留提示与尝试次数；每次改动保存成功才生效。
- 新独立存档 `user://profiles/workshop-gw07-1/save-v1.json`，不读写、不删改其它关卡档案。持久化压制与冷却的开工拍、阶段、对白停点、提示级别；开工拍只能排在第0到第11拍之间，越界或非整数判为损坏档。
- 沿用SaveRepository事务、失败重试和损坏档保护。单独临时测试档不接触玩家进度。

## 场景与后续

保留已认可的装配间背景与压机、冷却机、暂存位源图；小岚由宿主常驻现场。上排压制带、下排冷却带从第0拍到第14拍逐格对齐，第4～5拍检修区标红；暂存位占用、冷却冲突与完工时刻由引擎绘制。手动逐步停顿便于比较，失焦和模态暂停表现。

冷却带一路排满后，嗒嗒发现「停机前就要安排等待」，旧仓翻出一块没配牌的槽板。只完成 GW07，不扩展 GW08、跨岛解锁或伙伴加入。

## 验证

规则测试独立枚举四件货压制与冷却开工拍的全部整数组合（0～11），用独立的逐拍扫描判定重演每一套排法，验证合法解与最早完工下限（第11拍），并核对每套的检修冲突与暂存位溢位判定。窗口测试覆盖1280×720、960×540的输入、错误试运行、暂存位溢位、检修冲突、换带换货、撤销、保存失败重试、重载、发现卡及损坏档保护。实际命令与候选身份见 `docs/playtest/workshop-gw07/verification.json`。

这些检查证明规则与交互实现；小学三年级学生的实际挑战感、理解和学习效果仍须真人试玩。
