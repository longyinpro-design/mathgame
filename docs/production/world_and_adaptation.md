# 群岛世界、叙事与自适应

2026-09-10 实现更新：森林岛18关与正式会话、RPG、独立存档已进入引擎；当前运行事实和验证范围见[运行时与验证](runtime.md)。下文保留制作契约，历史“待实现”描述不作为当前进度，进度以唯一执行计划为准。
本文定义森林岛之外的延展边界及首岛配套系统，已同步普通关v2与首领v3（2026-09-10）。六岛主题延续既有产品方向，首岛以外的角色、机制和具体关数仍是规划。AI 是受约束的表达和选择接缝，当前没有在线调用。

导航：世界与六岛 → 探索任务 → 叙事 → 本地自适应 → 在线 AI → 配套功能。

## 1. 世界与六岛章节

数字群岛的旧航路依靠各岛居民共同维护。长久无人照料后，货运、分配、生产、空间与水路失去联系。小岚与阿橙从送一袋种子开始，把彼此孤立的生活重新连起来。伙伴是当地生活的一部分，数学能力体现它们观察世界的方式。

| --- | --- | --- | --- | --- |
| 森林岛 | 运输、三门借光、分仓、磨坊辨识、邮路、守护者约定；守恒、时刻约束、信息选择、分类、对策 | 搬运/分配、倒推、画路线、取物分组 | 三位伙伴、营地、首张跨岛航图 | 本轮逐关设计与数学验算 |

## 2. 探索、任务和世界变化

首岛采用小型连通区域：点击地面移动、走近对象交互，区域内有明确路径与热点。机关进入专注操作视图，退出回到来源位置。世界地图只显示已制作的真实入口；装饰建筑不能假装可进入。

任务使用作者定义的有向无环前置关系和有限状态：`locked → available → active → resolved`。回访是 `resolved` 的场景表现，不重置任务。并行任务可同时 available，手记允许选一条追踪；玩家不会因为未选择追踪而丢失进度。

首岛主线以关卡完成事件解锁；可选支线不会作为主线前置。苔团与折羽的个人经历与章节事件关联。系统根据已提交事件选择场景状态，例如树屋发芽、村仓恢复、邮旗升起、古林打开、营地庆祝。

NPC 初始每人制作 3–4 个有区别的故事状态及一个可循环日常动作。日常动画只表现搬果子、整理邮件、浇水等已成立事实，不写玩家关卡状态。首版时间由故事节点推进，不使用真实昼夜或离线计时任务；玩家可以随时停止。

## 3. 叙事与对话契约

每个任务有明确受助者、可观察的问题、玩家动作、完成后的生活变化，以及伙伴的一句独立反应。短对白一次承载一项关键信息；目标留在场景/手记中，不能只出现在自动关闭气泡里。

对话记录 `dialogue_id + node_id + seen`。内容由可核实的世界事实驱动；不能出现尚未加入的伙伴讲话、已完成任务又索要同一物品、或未发生事件被写成回忆。分支选择主要改变回应、支线访问顺序与角色偏好，不让一次措辞选择永久丢失主线能力。

关卡失败由对象表现具体原因：等重不动、分配不符、逆转次序不对、重复路线、对手留下关键局面。伙伴鼓励观察，不把失败写成智力评语。首领v3采用风枝石灵的接招试炼与雾冠树心的唤醒战；转移、变招、侦察和蓄力都直接改变数学局势，最终形成合力反击。规则不使用角色攻击力跳过机关目标。

## 4. 本地自适应：先收集事实，再选择下一关

按概念记录 `balance_conservation`、`reverse_state`、`temporal_constraints`、`information_choice`、`systematic_routes`、`strategy_blocks` 等 ID；完成一关可以贡献多个事实，但一次答对不自动判定掌握。

证据标签采用：`observed`（进行过）、`assisted_completion`（使用提示完成）、`independent_completion`（本次未用提示）、`transfer_observed`（在作者指定的不同情境、未用提示完成）。这些是历史事实，不是能力评级。首领另记录有效回合、撤销和此前观测，区分首次连续规划与依据反馈重新规划；撤销不自动计为主动提示，也不能因提示为0就推断首次全分支规划成功。提示后的同参数重做仍可记录完成，不能立即当作独立迁移证据。

首版选择策略只选作者已验算的内容：

1. 故事依赖决定下一组可用关，不能被学习模型改写。
2. 上次主动请求帮助且还没取得同概念独立证据时，下一次默认保留图形支架，并提供“再试一次”的可选练习。
3. 两个不同情境已有无提示完成事实时，提示一条可选迁移挑战；玩家可以拒绝，主线奖励相同。
4. 当前关开始后锁定规则、参数和队伍；FL06隐藏机器类型、FL15异晶位置、FL12对手分支、FL17敌方回应ID与FL18隐藏形态同时固定并保存。只在新的 `ChallengeRun` 创建时选择 variant。
5. 若没有匹配的已验算 variant，直接使用作者基础版并允许玩家请求支架；不临时拼出未验算题目。

v2中FL03/FL02比较状态恢复；FL07/FL05/FL06比较何时证据足够；FL15/FL06比较一次试验与分支称量；FL11/FL13比较新增载重/到站条件；FL17与FL02/11比较有限手牌和敌方换盘；FL18与FL05–07比较辨识后还须留足合击资源。按不同数学情境与规则版本记录近迁移/迁移候选，不能仅因场景换皮或连续通关就标为迁移成功。实际价值仍需观察玩家自己的策略和过程证据。

这一首版不拟合隐藏“能力分”、不靠反应速度调难度、不把错误次数作为惩罚。不足证据时保留 `unknown` 的事实状态；不编造精确掌握概率。

## 5. 在线 AI 接缝与降级

后续服务可用于受控 NPC 措辞、已经授权的氛围事件表达和下一次挑战候选排序。作者内容仍拥有故事节点、角色身份、事实、提示含义和完整主线。

拟定请求字段仅包含 `locale`、已见故事节点 ID、当前伙伴 ID、可选内容 ID 集合、离散学习证据标签和本次表达任务。默认不发本地存档、真实姓名、年龄、设备标识或自由聊天记录。供应商、费用上限、允许发送字段、保留方式和用户可见开关须在接入前确定。

模型输出限制为已给出的节点/候选 ID 与短文本。返回后检查 ID 允许集、当前事实前置和文本长度；失效、超时、供应商不可用或玩家关闭服务时使用作者模板。AI 不生成可执行脚本，不写奖励/背包/档案，不裁定数学成功，不修改进行中题目的规则。

首岛阶段可以制作本地固定样例验证这个接口；样例输出必须标记为模板/测试数据，不能宣称在线 AI 已接通。在线接入不阻塞主线、伙伴成长或保存恢复。

## 6. 其他系统的首版边界

| 系统 | 首版交付 | 后续扩展 |
| --- | --- | --- |
| 图鉴 | 三位伙伴的已见/加入/共同发现；解锁插图和来历 | 新岛生态、外观分支 |
| 手记 | 当前目标、关卡发现、伙伴事件、使用过的提示；可回看关键对白 | 更丰富的玩家标记和回忆页 |
| 收藏与隐藏内容 | 四条可选支线及各自纪念物；入口通过探索线索提示 | 隐藏岛、组合收集与支线故事 |
| 练习 | 已完成关的独立练习记录、同样的撤销与提示；不重复首通奖励 | 更多经过验算的作者变式 |
| 设置 | 音量/静音、输入说明；正式 UI 增加重复演出缩短与目标常显 | 平板输入、字幕/文本大小的专门实机验收 |
| 教学记录 | 本地事实记录，供系统选内容及开发试玩观察 | 家长报告须另做信息设计与验证；不自动生成学习诊断 |
| 联网与运营 | 单人离线可完整游玩 | 账号/云档/多人、支付和排行榜均需独立产品决策 |

目标儿童试玩观察“能否理解目的、是否主动试验、能否解释机关变化、是否关心伙伴、换情境后采取什么办法”；记录困难位置用于修订，不用自动化通过替代真人结论。
