# GW01 · 装不满的最后一托

2026-09-22。用户授权完成第三岛首关。设计来源是独立工作树的 `workshop_chapter.md`（提交 `6f97064`，第6节 GW01）；本文件冻结此次单关实现范围。

## 可玩内容

启动 `启动齿轮工坊GW01样板.command`，或直接运行 `game/workshop_gw01.tscn`。

开场由玩家逐句推进，先看空车与升降台错过，再主动开始整理。码头有23根灯轴、5个托盘（初始3槽），每托可选3槽或5槽衬板，维修盒容量2根且必须保留至少1根。五托都装满、维修盒1～2根、原处0根才验收。可接受的组合是三个5槽和两个3槽，位置任意（10种排列），共21根，维修2根。四个5槽加一个3槽虽恰好23根，但没有维修预留，不能验收。

点选后可放1根、补满一托/补满维修盒、取回1根；空托才能换板，防止换小板时货物消失。换板可撤销，重摆取回所有货物但保留衬板选择；撤销重摆可恢复整套配置。此改版已获用户授权，重点从固定分组转为容量组合和预留约束。

验收后第一托移上升降台，小车仍空着经过；另外四托及维修盒的货物保留现场。玩家再逐句读后续戏，确认“配好大小托”发现卡，结束第一关。下一关尚未实现，不提供无效跳转，也不提前让嗒嗒加入伙伴队伍。

## 操作与状态

- 鼠标/点选即可完成；`1–5` 选托盘，`6` 选维修盒；`A` 放1根，`B` 补满托盘/盒子，`D` 取回1根，`C` 切换空托衬板；`Z` 撤销，`X` 确认重摆，`H` 四档主动提示，`Space` 继续/验收。Tab 与按钮焦点可访问所有现场操作。
- 重摆和重玩均有确认；撤销与重摆不撤销已使用提示与验收次数。第四档清楚标为示范。
- “回看与发现”保留已读开场；完成后展示数量关系和发现卡。不追加填数、口试或等待倒计时。
- 使用现有 SaveRepository，单独存档 `user://profiles/workshop-gw01-2/save-v1.json`。旧版独立存档原样保留，新玩法从开场开始，不将旧通关状态当作新关卡完成。每个稳定操作先验证与保存，成功才安装和演出。保存失败保留已提交状态与候选，重试同一候选；损坏档先保护，再由玩家确认备份重开。
- 只保存数量、衬板容量、阶段、对白停点、提示级别和验收次数；选择、动画进度与撤销历史为会话状态。动画中退出后从已保存阶段重播，跳过效果与自然结束相同。
- 此样板不读取第二岛完成凭据，不修改森林/集市档案、奖励或正式跨岛解锁。正式旅程中的 MK18→回信→靠泊衔接仍是后续范围。

场景沿用首批错拍码头原图。`assets/runtime/workshop/gw01/manifest.json` 记录 AtlasTexture 区域和锚点；不改源图像素。托盘三个或五个槽、数量和选中框由 Godot 绘制，不能用生成图的细节判定规则。嗒嗒当前用一个离散待机姿态；小岚与阿橙复用既有源图。货物动画排除目的地静态副本，确保每根灯轴在画面上只有一个归属。升降台和货车的运动仅用于表现错拍，没有时间作答规则。
