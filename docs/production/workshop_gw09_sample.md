# GW09 · 既不漏灯，也不错站

2026-09-25。按 [GW01契约](workshop_gw01_sample.md) 同一套三年级奥数难度与制作原则实现。核心思考是「循环规律、同时满足条件」：先找回 0 前能停遍每一盏的步长，再用旧记录筛掉第 3 站不对的候选。不是原章节里的基础循环题，也不声称已通过儿童难度实测。

## 可玩契约

环上 12 盏灯编号 0～11，从 0 出发，每次固定走 2～8 格，顺时针且途中不改步长。第一次回到 0 之前要把 1～11 每一盏都停到，只跨过而未停下的灯不算访问；起点不算第 1 次跳动。旧报时记录还写着「第 3 次跳动后停在 9 号灯」。

回 0 前能停遍每一盏的步长只有 5 和 7：5 格第 3 站是 3 号灯，7 格第 3 站才是 9 号灯，所以唯一解是 7，轨迹 0、7、2、9、4、11、6、1、8、3、10、5、0。步长 3 第 3 站正好是 9，却第 4 跳就回到 0，漏掉 8 盏；步长 5 虽然全覆盖，第 3 站却不是 9。局部对不算过，两条要同时成立。

- 步长、第 3 站预测、跳数与停站记录全部由规则模块现算；画面不另存轨迹，换步长不会留下旧判定。
- 逐跳运行，停下才算访问；回 0 的那一跳结束这一圈，提前回 0 会念出漏了几盏。
- 第 3 站预测只能写在第 3 次跳动落地之前；跑过第 3 站之后要重跑这一圈才能改口。
- 四档主动提示依次为：先检查看似对的 3 格会不会回早了 → 找不漏灯的候选 → 再核对第 3 站 → 7 格完整示范。默认不显示解。

## 操作与存档

- 启动 `启动齿轮工坊GW09样板.command` 或 `game/workshop_gw09.tscn`。
- 鼠标完整可玩；点 2～8 的步长牌设步长，点 0～11 的灯写第 3 站预测，点「跳一格」逐跳运行，←/A 与 →/D 移动步长，Q/E 移动预测，J 跳一格，R 重跑这一圈，Z 撤销，X 确认重摆，H 主动提示，Space 报时校准。保留 Tab/Enter 焦点操作。
- 重跑、重玩有确认。撤销与重摆保留提示级别；每次改动保存成功才生效。
- 新独立存档 `user://profiles/workshop-gw09-1/save-v1.json`，不读写、不删改其它关卡档案。持久化步长、第 3 站预测、跳数、停站记录、阶段、对白停点、提示级别；越界步长与灯号、对不上步长的停站记录判为损坏档。
- 沿用 SaveRepository 事务、失败重试和损坏档保护。单独临时测试档不接触玩家进度。

## 场景与后续

沿用已认可的装配间背景与报时铃、双空表盘、嗒嗒母版。12 盏灯围成一圈，0 号在最上面顺时针编号；轨迹、停站顺序、回 0 的那一跳与第 3 站判定由引擎绘制，下一跳只预览一格，第 3 站仍要自己数。旧记录牌、步长牌与预测灯号排在同一块控制板上。失焦和模态暂停表现。
