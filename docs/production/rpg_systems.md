# RPG 收集、伙伴养成与营地

2026-09-10 实现更新：森林岛18关与正式会话、RPG、独立存档已进入引擎；当前运行事实和验证范围见[运行时与验证](runtime.md)。下文保留制作契约，历史“待实现”描述不作为当前进度，进度以唯一执行计划为准。
本文是森林岛正式设计，已同步普通关v2与首领v3（2026-09-10），覆盖三位原创伙伴、成长、队伍、技能、奖励与营地。当前试玩仅有阿橙的两个剧情成长节点和一个石灵信物；下述等级、队伍、入队、建设系统均待实现。关卡编号见 [森林岛](forest_chapter.md)。

导航：成长目标 → 伙伴 → 队伍技能 → 数值 → 营地经济 → 界面与验收。

## 1. 玩家为什么愿意培养伙伴

伙伴先作为角色出现，拥有自己的困难、偏好和反应；共同完成事件后主动加入。培养的回报是更丰富的相处、更有辨识度的外观、可选择的数学操作工具与可回访的新情节。首岛让玩家体验一次完整的“认识 → 一起行动 → 成为伙伴 → 配置能力 → 共同成长”。

结识使用固定故事事件，没有捕捉概率、抽卡或重复收集同名个体。首次通关即可得到主线奖励，使用提示、反复尝试和慢慢思考都不降低经验与羁绊。过程证据也可借助提示完成；普通关界面不设置与真实任务不同的“免证明领奖”旁路；首领按战斗目标和有效轨迹判定，不额外补填普通关证明板，辅助完成按事实记录。挑战支线提供额外故事、收藏与证明任务。

## 2. 三位伙伴角色卡

| ID / 角色 | 个性、初遇与加入 | 数学操作身份 | 首岛关系与外观 |
| --- | --- | --- | --- |
| `acheng` / 阿橙 | 好奇、愿意先试；开场已同行，会记得自己下篮后重量改变 | 标记对象、记录试运行前的想法、对比前后变化 | FL01、FL06、FL12 各产生一次共同经历；三次后在营地选择系上“同心叶结”，获得成长外观 |
| `mossling` / 苔团 | 石灵守护的一只小石芽；谨慎、喜欢让物件稳稳站好；FL02完成三门借光及倒放板后认识并入队 | 将玩家选定的离散对象组成可搬运的组，展开组查看每个单位 | FL03 的分仓、FL11的轻装规划、FL18唤醒树心的合力分别产生羁绊；首岛有新动作/营地石凳，外观进阶留给后续岛 |
| `feather` / 折羽 | 林间送信的小鸟；热心但会遗漏路线；FL08 帮它整理邮路后入队 | 记录玩家画出的路线、标记分叉、叠放两次尝试比较 | FL09 或 FL10 的邮路事件、FL17的接招及营地寄信产生羁绊；首岛制作羽饰和送信动作 |

每只伙伴记录 `seen`、`joined`、`bond_event_ids`、已解锁技能及外观选择。初遇图鉴只显示已经看到的信息；未来岛伙伴显示轮廓与生态线索，不提前揭示剧情。石灵本体作为 NPC 留在古林，苔团是新伙伴，避免把旧信物直接等同于已收集的宠物。

羁绊事件由故事唯一 ID 产生，不按点击次数累积。重复营地互动可播放不同短反应，但不会无限刷关系。后招募伙伴仍能通过回访取得其对应事件；每个事件每个伙伴至多一次。

## 3. 队伍与能力

首島收集三位伙伴，出行队伍最多两位，一位领队在探索时跟随，另一位在能力操作时出现；其他伙伴留在营地。营地或关卡开始前可以免费调整队伍。关卡开始后队伍与技能配置随 `ChallengeRun` 固定，中途返营地保留关卡状态，再进入恢复原配置。

主线的基本操作始终由场景工具提供：玩家即使没有带苔团也能逐枚搬运，没带折羽也能用邮路板记录路线。带上伙伴提供更自然的组合操作和角色反馈；主线不会出现“已经进入但因为少带伙伴无法完成”。明确需要某位伙伴的个人支线，在入口显示条件并允许直接打开队伍页。

机关的任务角色清单与出行技能队伍分开。例如 FL11 的阿橙是这次订单明确指定的旅客，即使不在当前两人队伍也按剧情到站参与；其他伙伴在站台旁观察，不被暗中加入载重。角色重量、数量和任务对象在进入关卡时明示并固定，换队不能改变题目参数。

| 伙伴技能 | 解锁条件 | 玩家做什么 / 状态怎样改变 | 学习记录 |
| --- | --- | --- | --- |
| 阿橙·观察签 | 开场 | 玩家选择物件贴上标记；不生成答案或推荐落点 | 普通工具，不记提示 |
| 阿橙·前后手记 | FL06 完成 | 玩家保存一次预测，试运行后并排看自己的预测和结果 | 普通工具；若主动请求指出差异原因，则走分层提示 |
| 苔团·抱团搬运 | FL02 加入 | 玩家选定同源可搬物件形成组，一次搬运展开成确定的逐单位变化；总数守恒，整组不合法则整次拒绝 | 普通操作，不记提示 |
| 苔团·分组带 | FL11 完成 | 玩家圈定每组数量，把现有对象按自己的划分排列，可展开复核 | 记录玩家分组证据；系统不自动选择关键组大小 |
| 折羽·路签 | FL08 加入 | 玩家给已经画出的路线加签，按自己选择的第一步分类 | 普通工具；重复路线按关卡规则标记 |
| 折羽·试走影子 | FL10 完成 | 播放玩家已画的路线，显示实际经过的格点和碰撞位置 | 试运行，不自动补全剩余路线 |

每位伙伴最多装备两项已解锁技能；首岛恰好各两项，先验证队伍切换和动作表现，后续岛再引入真实的多技能取舍。没有冷却与耗蓝挡住思考。技能的演出需要准备、执行、结果和收回四个节奏点，可在不改判定的前提下缩短重复演出。

三级提示通过伙伴对白提供，但“使用技能”与“请求答案帮助”有明确边界：只要系统替玩家指出规律、推荐落点或演示关键步，就记录对应提示层。不能把自动求解包装成不计帮助的伙伴被动能力。

## 4. 三套独立成长数据

| 数据 | 来源与展示 | 用途 |
| --- | --- | --- |
| 行旅经验 `journey_exp` | 每关首次完成；所有已加入伙伴显示同一行旅等级，新加入直接使用当前等级 | 外观细节、动作表现与图鉴旅行记录；不改变机关数值 |
| 羁绊 `bond_event_ids` | 每个角色卡列出的共同故事事件，按唯一 ID 计数 | 个性对话、个人故事、阿橙一次成长外观 |
| 学习证据 `LearningObservation` | 当前关是否完成、使用哪些提示、证明/变式操作 | 选择下一次可用挑战和支架；不作为 RPG 经验、排行榜或能力标签 |

首岛等级阈值：Lv1=0、Lv2=40、Lv3=100、Lv4=180、Lv5=280，总经验累积不归零。FL01–FL12 每关首次 +20，FL13–FL16 每关 +10，FL17/FL18 每关 +30。仅完成必经 14 关可得 300，达到 Lv5；全章 340。Lv5 达到后经验继续记录，首岛不再提升等级。

这套数值是首轮制作参数，待真人节奏验证。能力依赖故事解锁，不以等级锁主线。新伙伴共享等级避免补刷；角色差异来自羁绊、技能和行为。阿橙成长须完成 FL01/FL06/FL12 三个经历并回营地触发，玩家可以稍后观看，完成状态与外观选择独立保存。

## 5. 奖励、背包与营地经济

背包分为永久任务物（种子来信、石灵信物、岛屿航图）、营地木片、收藏物与已解锁外观。任务物使用集合，不能卖出或消耗；主线需要它时检查故事事件。首岛仅一种可花材料“营地木片”，避免多个货币的兑换负担。

| 来源 / 用途 | 木片数 | 条件与可见变化 |
| --- | --- | --- |
| FL01–FL12 首次完成 | 每关 +8 | 在关后与经验一起结算 |
| FL13–FL16 支线 | 每关 +4 | 额外收藏和伙伴反应，不是建设必需 |
| FL17、FL18 首领 | 每关 +12 | 岛屿推进与庆祝 |
| 修好营地屋顶 | -30 | FL04 后开放；屋顶、暖光、休息动作变化 |
| 建造伙伴工台 | -40 | FL08 后开放；三个伙伴有可见互动位置 |
| 完成纪念花圃 | -50 | FL18 后开放；展示种子、信物与首島回忆 |

主线收入 `12×8 + 2×12 = 120`，三项建设花费 `30+40+50 = 120`；支线额外 +16。每项只能购买一次，没有重复消耗；任意购买顺序都不会减少主线可用能力。入口检查开放事件、木片余额和未建造，扣款与建筑事件一次保存。

不设置主线体力、消耗性提示、修理损耗、伙伴饥饿惩罚或随机数值装备。后续岛可以加入可选择的工具和纯外观装备，但须有具体操作用途；不能通过攻击力跳过数学条件。

营地每次重要变化要看得见：初始空位 → 出现施工准备 → 玩家确认建设 → 完成外观与伙伴动作。保存失败停在未提交的建设意图，重试不能再次扣款。回访旧关以观察世界和伙伴反应为主；再练习使用新练习记录，不重复首次奖励。

## 6. 界面、故事回报与验收

伙伴页采用现有手记纸张：左页伙伴形象、行旅等级与关系事件，右页当前两项能力和一条正在进行的个人故事。队伍位直接展示谁在同行；空位可点击配置。背包用物件图标和用途说明，任务物旁显示来源事件。营地建设通过场景对象交互，不另做脱离世界的商店大厅。

一次关后只集中呈现“世界改变 + 一个主要伙伴反应 + 奖励归档”；长列表可在手记展开。学习记录使用事实描述，如“在磨坊尝试了倒着走”“这次用了第二层提示”，不显示天赋、智力或百分比掌握度。

首个 RPG 验收闭环：新档与阿橙出发 → FL01 结算 → 经验/木片/第一条羁绊各一次 → 回营地看到关系反应 → 关闭重开恢复 → 回访不重复奖励。后续验证苔团/折羽入队追平等级、队伍配置恢复、FL12 成长只触发一次、建设经济和提示奖励独立。

首领v3的剧情角色分工：阿橙保留玩家标记/现场观测，苔团表现台座和储备保护，折羽表现交换轨迹/侦察投送；它们不会自动选择正确符石、预告最优侦察包或免费生成种子。首领胜利仍使用原稳定奖励ID，FL17折羽经历、FL18苔团经历与航图保持原解锁位置。
