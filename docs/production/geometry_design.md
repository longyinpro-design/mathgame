# 几何山谷：作者契约与验证

本章是本地原生 Godot 机关，不调用在线模型。运行环境验证为 Godot 4.6.3，不声称 4.7 或 macOS 验收。

## 关卡

GV01 旋转 L 形转角桥；GV02 翻面改变四格阶梯手性；GV03 两根多米诺的方渡口；GV04 三块 L 石的九格不规则院落；GV05 左右镜像花园；GV06 双轴花纹闭包；GV07 六格最短围栏；GV08 同面积不同周长；GV09 绕井、保留三点的多约束梯田；GV10 一刀截梁割补；GV11 双刻痕三段割补；GV12 留空中心的环形回廊。

可选 GV13 斜轴镜像，GV14 半转对称，GV15 恰好两片药田，GV16 两块 L 亭与两块折亭组成方院。支线均不作为主线前置。

GV17 镜岭守护者有两道不同手性石盾。每次封印保存真实石块坐标和变换，校验器重新计算覆盖，不信任完成布尔值。GV18 山谷建筑师先要求六格、周长十四的连片地基；落石由已封存地基的空角确定，再要求避石并把同面积花圃周长减至十。落石不重抽、不由场景任意选择。

## 数学边界

拼接采用单位方格集合、四种旋转和两种翻面，归一化局部坐标后放置。面积由实际格子数计算；重复占格、越界、目标外落点均非法。割补后的每块形状由作者定义，独立测试确认总面积守恒。

花圃周长逐格统计四条邻边，存在相邻格时该边不属于外沿。连通仅使用四邻域，角接触不算连通。金色种子不可移除，禁种岩石不可覆盖。对称逐格检查对应伙伴，接受所有合法构造。

GV07 的目标十条边经独立穷举所有 4×4 网格中六格子集证明为全局最小值。运行时仍以实际形状而非输入数值判断。GV18 全部可达落石分支经独立枚举验证有合法紧凑回应。

## 模块与验收

scripts/geometry/levels.json 保存作者参数、目标、约束、对白、提示和奖励，不含解答。catalog.gd 规范化整数并返回深副本；rules.gd 是纯状态规则；level_scene.gd 继承共享事务宿主；world.gd 只绘制真实棋盘。

tests/geometry/oracle.py 是独立 Python 集合枚举器；生成测试动作见 witnesses.json，计数见 docs/playtest/geometry/oracle_results.json。test_rules.gd 通过真实动作完成十八关，覆盖输入不变、非法动作、闭合 schema、NaN 拒绝、首领伪造证明拒绝和 JSON 往返。test_ui.gd 经 InputEventMouseButton 驱动按钮和格子，再从共享存储重读，不直接设置完成标志。

绘制采用山谷石色、积雪峰、干砌梯田、带木纹操作台、接地棱角伙伴。完成灯由实际 solved(board) 驱动，没有参考解覆盖层。自动化不替代儿童试玩。
