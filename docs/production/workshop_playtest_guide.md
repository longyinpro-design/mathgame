# 齿轮工坊 · 真人试玩观察指南

2026-09-25。给第三岛（GW01～GW18）做真人试玩的人用。回执与实窗测试只证明规则、交互与表现实现；**孩子是否理解、是否觉得难、有没有学到东西，只能靠这一份观察**。本指南不预填结论，也不把「通关」写成「已掌握」。

## 准备

- 逐关启动：`启动齿轮工坊GWNN样板.command`（或在 Godot 里开 `game/workshop_gwNN.tscn`）。每关是独立存档 `user://profiles/workshop-gwNN-1/save-v1.json`，互不影响。
- 两种窗口都跑一遍：1280×720 与 960×540。看目标、规则、物件与对白是否同时可读。
- 至少一遍只用键盘（Tab/Enter 焦点、方向键、Space 与各关标出的快捷键），确认不靠鼠标也能走完。
- 音效在运行期合成、没有音量开关，试玩前先听三处：GW09 的报时（逐跳升调、提交后 12 盏一盏盏响、收尾长铃）、GW13 的合鸣、GW16 的午休铃（试听与交付按每段拍数敲）、GW18 出海三声。嫌吵、听不出段长或听不出「一起叫」，都记下来。
- 只记现象，不纠正孩子：他说了什么、卡在哪一步、按了几次提示、有没有读台词板。

## 通用观察

- 卡住时他先做什么：乱点、反复按同一个键、还是回头看规则牌。
- 提示四档（H）是不是按「提醒观察 → 给支架 → 示范比较 → 明确下一步」的顺序起作用；哪一档开始变成念答案。
- 台词板（开场 3 句、收尾 3 句）是读完还是直接跳过；跳过之后还能不能说出这一关在干什么。
- 撤销（Z）与重摆（X）用不用得上；错了以后是重来还是想办法改。
- 一关的净时长（从进场到通关）与「读规则」占的比例。主要时间花在拖格子或读长规则上，就该减操作、分步呈现，而不是加数字。

## 逐关要看的那一点

| 关卡 | 只看这一件事 |
| --- | --- |
| GW01 被蒸汽抹去的货单 | 会不会从「出发时的 24 根」倒着想，而不是从眼前三托往前凑 |
| GW02 留样之后，还缺多少 | 有没有把「做出来的数量」和「能拿去安装的数量」分开记 |
| GW03 相遇了，还不能交接 | 两只铃相遇时，是否明白相遇不等于能交接 |
| GW04 两班船，都要赶上 | 等待的时候会不会说清「在等谁」；等待有没有被当成浪费 |
| GW05 七拍能做完吗 | 会不会坚持把两班排成一列，还是愿意并着排 |
| GW06 产量一样，工时不同 | 比较时看的是产量还是总工时 |
| GW07 检修前，先留好位置 | **会不会只想加速**：堵住时反复按加速，还是想到留一格 |
| GW08 两张旧单，锁定一块槽板 | 是否从两张记录里找同一块槽板，而不是各算各的 |
| GW09 既不漏灯，也不错站 | 是先找「不漏灯」再核对「第 3 站」，还是只盯第 3 站 |
| GW10 最急的那单，为什么不能先开 | 愿不愿意先做别的单，能不能说出「先开最急」会挡住谁 |
| GW11 两张船票，倒排到同一张台 | 会不会从船票往回排，而不是从材料往前试 |
| GW12 两班合起来，槽数才找得到 | 有没有把两班余料合起来数 |
| GW13 两只鸟，到底叫了几次 | 同一拍两只一起叫，会不会被数成两次 |
| GW14 第三张记录才有用 | 是否明白单张记录筛不掉、三张一起才能定 |
| GW15 最早的一次观察 | 「最早」的口径是否说得清（第 9 拍为什么是最早） |
| GW16 找全四种午休曲 | 是分类着找（按首段），还是一首一首乱试；试听的响法帮不帮得上 |
| GW17 巡轨兽 · 空出第一拍 | 敢不敢第一拍不发车；能否说清四辆车各自的最晚驶离 |
| GW18 百臂总机 | 是否分得清**产量够、暂存有位、赶上交接**这三件不同的事 |

## 章末与剧情衔接

- GW04 之后、GW08 之后、GW18 之后各有一次剧情收束：孩子能不能说出「等待也有作用」「先找记录，不急着找坏人」「把空位留给人」。
- GW18 收尾：小岚旁边的山谷退件包、阿舷递包的姿势、嗒嗒挂上的休息牌、总机只留一只臂——问他看到了什么。他如果只看到「船开走了」，说明章末镜头还需要更明确的一拍。
- 关间钩子：上一关收尾提的下一件事，下一关开场有没有接上（GW11→GW12→GW17/GW18）。

## 与回执的关系
