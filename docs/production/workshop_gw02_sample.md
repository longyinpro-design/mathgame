# GW02 · 留样之后，还缺多少

2026-09-24。按 [GW01契约](workshop_gw01_sample.md) 同一套三年级奥数难度与制作原则实现。核心思考是「还原总量、假设替换」：先把两种留样补回总产量，再比较大小模的单片差额。不是原章节里的基础分组轻关，也不声称已通过儿童难度实测。

## 可玩契约

护栏需要27枚可安装卡销。架上有8片铜料，全部使用；每片选四孔模或七孔模，一次产出4或7枚。两种模都要开，且每种模第一次加工的一整批必须封存检测，不能装到护栏上；之后的整批都安装，不另留余料。

先把两盒留样补回总产量：一盒4枚、一盒7枚，共11枚，所以8片应共出 27+11=38 枚。假设8片全用四孔模只得32枚，比38少6；每换一片七孔模多3枚，6÷3=2，所以七孔2片、四孔6片。28种位置排列全部合法，没有换模成本。

- 封存批次不是额外铜料，不能把留样同时算作安装；只凑27而忘记留样不合法。
- 数量、留样与安装数全部由 `molds` 现算，画面不另存计数，改一片铜料不会留下幻影产量。
- 四档主动提示依次为：样品也是产量 → 补回两盒共多少 → 全用小模与目标差多少 → 38−32=6、每换一次加3、共换两片。默认不显示解，也不自动填模。

玩家可先给8片逐片盖章，选满8片就允许试压，无须预先通过答案判定。试压按排产顺序逐片演出，每种模第一次加工的那一批落进对应的透明留样盒；错答案也看得到这一台出了什么，宿主只拦「还没选满」。跑完对照安装数，主动确认才进入剧情，也可中途重选模具。

## 操作与存档

- 启动 `启动齿轮工坊GW02样板.command` 或 `game/workshop_gw02.tscn`。
- 鼠标完整可玩；1/2选四孔模/七孔模，Q/W/E/R/T/Y/U/I 逐片盖章，Z撤销，X确认重摆，H主动提示，Space试压。保留Tab/Enter焦点操作。
- 重摆、重玩有确认。撤销与重摆保留提示与尝试次数；每片保存成功才落下模具。
- 新独立存档 `user://profiles/workshop-gw02-1/save-v1.json`，不读写、不删改其它关卡档案。持久化模具选择、阶段、对白停点、提示级别、尝试次数；产量与安装数由模具现算，越界模具、非整数、错长度都判为损坏档。
- 沿用SaveRepository事务、失败重试和损坏档保护。单独临时测试档不接触玩家进度。

## 场景与后续

保留已认可的装配间背景与铜板、压机、留样盒、护栏源图；小岚由宿主常驻现场。8片铜料排在工作台上，压机按顺序逐片落下；模具孔位（四孔两行两列、七孔三行3+2+2）、留样与安装数全部由引擎绘制，母版只提供造型。试压有手动逐片停顿便于比较，失焦和模态暂停表现。

护栏修好，玩家可登观察台。嗒嗒发现「做出的数量」和「能拿去安装的数量」需要分别记。只完成GW02，不扩展GW03、跨岛解锁或伙伴加入。

## 验证

规则测试独立枚举8片铜料在四孔/七孔两档下的全部 2^8 种模具配置，用独立标量计算验证唯一解（七孔2片、四孔6片，共28种位置）以及每片封存与安装的判定。窗口测试覆盖1280×720、960×540的输入、错误试压、试压回放、重选、撤销、保存失败重试、重载、发现卡及损坏档保护。实际命令与候选身份见 `docs/playtest/workshop-gw02/verification.json`。

这些检查证明规则与交互实现；小学三年级学生的实际挑战感、理解和学习效果仍须真人试玩。
