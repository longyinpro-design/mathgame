# GW06 · 产量一样，工时不同

2026-09-24。按 [GW01契约](workshop_gw01_sample.md) 同一套三年级奥数难度与制作原则实现。核心思考是「数量分类、计算额外成本」：先列出能凑出目标产量的组合，再把换模的额外拍数算进去。不是原章节里的基础分组轻关，也不声称已通过儿童难度实测。

## 可玩契约

需恰好31枚扣环；小模每炉出3枚，大模每炉出5枚。每炉1拍，相邻两炉换模另用1拍，首次装模免费。原料充足，整炉加工，不丢弃；第8拍结束前全部完成。

凑31枚只有两种组合：小7炉大2炉（共9炉），或小2炉大5炉（共7炉）。9炉那一种光加工就要9拍，还没算换模，已经超过8拍；只剩7炉那一种。7炉加工7拍，还剩1拍只够换一次模，所以同类的炉次必须排在一起——合法顺序为 小小大大大大大，或 大大大大大小小。大小交错虽然产量对，时间不够。

- 产量与拍数由工单现算，画面不替玩家记数；同一拍不能既换模又开炉。
- 接受所有达到8拍且产量31枚的方案，不硬编码示例顺序。
- 四档主动提示依次为：先列产量组合 → 只有两种凑得出31 → 9炉光加工就超时 → 7炉只剩1拍、同类集中。默认不显示解，也不自动填关键中间量。

玩家编排最多10炉的工单，画面分别记录产量、加工拍和换模拍。工单空着不能试运行，先说清缺什么，不进演出；试运行错答案也能看到这一张工单实际几拍、差多少，宿主只拦「空工单」。

## 操作与存档

- 启动 `启动齿轮工坊GW06样板.command` 或 `game/workshop_gw06.tscn`。
- 鼠标完整可玩；Q加小模一炉，W加大模一炉，点工单上的炉次撤下来，R撤最后一炉，Z撤销，X确认重排，H主动提示，Space试运行。保留Tab/Enter焦点操作。
- 重排、重玩有确认。撤销与重排保留提示与尝试次数；每次改动保存成功才生效。
- 新独立存档 `user://profiles/workshop-gw06-1/save-v1.json`，不读写、不删改其它关卡档案。持久化工单、阶段、对白停点、提示级别、尝试次数；产量与拍数由工单现算，越界炉号、非整数、超过10炉判为损坏档。
- 沿用SaveRepository事务、失败重试和损坏档保护。单独临时测试档不接触玩家进度。

## 场景与后续

保留已认可的装配间背景与熔炉、模具、扣环源图；小岚由宿主常驻现场。熔炉带从第0拍到第12拍逐格对齐，每格标出这一炉的模与枚数、换模格单独标注；产量刻度条与时刻牌由引擎绘制，超出画面的拍数不画，总拍按左边的读数。手动逐步停顿便于比较，失焦和模态暂停表现。

减少开炉次数，灯架合拢。嗒嗒发现「把额外花费算进去」才挑得对方案。只完成GW06，不扩展GW07、跨岛解锁或伙伴加入。

## 验证

规则测试独立枚举最多10炉工单的全部 2^1+…+2^10 组合，用独立逐拍模拟器重演每一张工单，验证合法解恰为两种顺序、9炉方案超时、以及每张工单的产量与拍数判定。窗口测试覆盖1280×720、960×540的输入、错误试运行、撤炉、换模计数、撤销、保存失败重试、重载、发现卡及损坏档保护。实际命令与候选身份见 `docs/playtest/workshop-gw06/verification.json`。

这些检查证明规则与交互实现；小学三年级学生的实际挑战感、理解和学习效果仍须真人试玩。
