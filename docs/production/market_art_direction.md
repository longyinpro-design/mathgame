# 千灯集市：首批美术与场景化关卡

日期：2026-09-19。依据：[第二岛设计](market_chapter.md)、现有森林美术母版及本轮用户提出的“先画资源，关卡融入场景”。首批交付为源美术与表现方案。后续用户已授权 MK01 完整场景样板，独立实现及验证见 [样板契约](market_mk01_sample.md)；2026-09-20 用户授权按拆件包实现 MK02，见 [MK02样板契约](market_mk02_sample.md)。第二岛其余关卡仍为提案。

## 画面与操作的关系

玩家是帮助居民工作的旅行者。进入关卡时，镜头靠近刚才剧情里出现的接货台、货架或码头设备；场景、人物和货物连续存在。选择、搬动、试交与纠正都发生在这些物件上，完成后货物去往真实目的地，居民接着行动。

像素画负责材质、轮廓与气氛；引擎负责准确数字、对象数量、输入、状态和因果动画。生成图中的杯子、刻线、绳索及阴影不能直接作为运行时判定依据。概念整图用于确定构图，最终场景拆为海天、建筑、机关静态底座、活动部件、角色、前景和灯光。

采用近正面、轻俯视的工作台视角。远处街巷表现纵深，操作区尽量正交，保证杯槽、货位和目标不因透视误导。蜜橙、孔雀蓝、陶红与黄铜区分森林岛；光源统一左上。细节集中在边缘，中央操作区保持安静。

## 状态与交互必须一起制作

- 货物：在架、选中、搬运、已放置、已交付。货位与对象只保留一个真实归属，不用动画复制出额外库存。
- 杯与量槽：空、装满、倾倒；液面和准确刻度另画动态层。三类杯除了色彩还使用不同轮廓。MK01 操作只允许满杯选取。
- 铜秤：底座、横梁、悬索、两盘、物品及影子分层。旋转支点固定，盘面随梁移动且保持承托关系；摆动只反映已提交的规则结果。
- 灯：壳体、芯、熄灭/点亮与光晕分层；街道明暗记录已经完成的交付，不能提前泄露答案。
- 货签：实体纸张与夹子是美术，单号/数量/单位是引擎文本；不用 AI 烘焙文字承载规则。查看原单支持放大与键盘打开。
- 角色：脚底锚点与手持物挂点明确。扣扣是圆耳、短圆吻、尾夹的独立物种；不能画成戴围巾的阿橙。
- 首领：铜鹭准备/验货/展开平台；万签未履约/收回执/展开灯船。状态图仅指导后续拆件，不当作现成动画帧。

## 可读性与落地检查

场景化不等于把规则藏起来。目标放在操作物旁固定的小型铭牌上；长约定可展开，关键数量与限制常显。撤销、重摆、主动提示与设置使用稳定的小工具栏，不强行伪装所有系统操作。对白由玩家推进，消失后可回看。

交互优先级高于装饰：货盘应有明显轮廓、接触影子和选中反馈；前景不遮挡有效操作区。目标触控范围至少按 48 逻辑像素预留，实际在 1280×720 与 960×540 验证。拖动之外可“选物→选目标”，键盘可遍历每个独立对象。颜色与声音都不是唯一信息来源。

第一次引擎样板建议验证同一张码头台的完整连续过程：争执→镜头靠近→混合测量→比较回执→填写容量→交货验量→种子上岸→人物接戏。检查错误摆法、撤销、保存恢复、动画跳过与缩小窗口；这些检查已纳入后续 MK01 独立样板；当前结果见 `../playtest/market-mk01-reasoning/verification.json`，不代表其余17关已实现。MK02 育苗铺整组交换的同类检查见 `../playtest/market-mk02-exchange/verification.json`，同样不代表其余关卡已实现。

## 本轮证据边界

使用内置 image_gen 生成，源图来自本项目风格母版；未使用外部图库。人工检查构图、角色身份与明显对象数量，文件清单记录实际像素尺寸和 alpha 情况。道具图的透明像素保留底色 RGB，预览曾显示出该底色；已以实际 alpha 直方图纠正判断。图中最高 alpha 为254，仍需亮暗背景上的实体及边缘验收。万签的牛形轮廓为本轮造型探索，变形关节尚未设计。源图没有完成逐帧动画、严格像素网格统一、自动切片、引擎导入或真人试玩验收。工作目录不含 Git 仓库，因此没有生成提交。
