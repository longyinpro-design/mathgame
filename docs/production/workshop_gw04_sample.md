# GW04 · 两班船，都要赶上

2026-09-24。按 [GW01契约](workshop_gw01_sample.md) 同一套三年级奥数难度与制作原则实现。核心思考是「调整起点、比较整段」：把三档延后量各排一遍，比较整条时刻表的相遇记录。不是原章节里的基础分组轻关，也不声称已通过儿童难度实测。

## 可玩契约

小车第4、8、12、16拍到，每次接走一托。吊台原在第2、8、14拍到，周期6拍；开工前可整体延后0、1或2拍，此后不能再调。GW03之后余下的两托在新班次第0拍已备好，必须在第16拍结束前通过两次真实相遇送完。本关没有GW03的放行灯限制，换了独立直通轨，开局说明。

三档各排一遍：不延后吊台到2、8、14拍，只在小车第8拍碰上一次；延后1拍到3、9、15拍，一次也碰不上；延后2拍到4、10、16拍，正好在小车第4拍和第16拍各接走一托。所以取延后2拍、两次交接分别是4和16。只找到第一次4拍还没有完成整单。

- 相遇表由延后量现算，画面不另存时刻表；起点挪一挪，整张时刻表都会跟着变。
- 每次交接只能消耗一托，重复选择同一时刻不算第二次。
- 四档主动提示依次为：吊台每6拍、小车每4拍 → 三档各排一遍 → 不延后只有一次 → 延后2拍、4和16交接。默认不显示解。

玩家可先挑一档延后量，再点出两次交接。选满两次才允许试运行，没选够时先说清缺几次，不进演出；试运行错答案也能看到这一档实际碰上几拍，宿主只拦「没选满两次」。

## 操作与存档

- 启动 `启动齿轮工坊GW04样板.command` 或 `game/workshop_gw04.tscn`。
- 鼠标完整可玩；1/2/3选延后0/1/2拍，点刻度设为交接/再点取消，←/A、→/D移动光标，R把光标处设为交接，Z撤销，X确认重排，H主动提示，Space试运行。保留Tab/Enter焦点操作。
- 重排、重玩有确认。撤销与重排保留提示与尝试次数；每次改动保存成功才生效。
- 新独立存档 `user://profiles/workshop-gw04-1/save-v1.json`，不读写、不删改其它关卡档案。持久化延后量、两次交接、阶段、对白停点、提示级别、尝试次数；相遇表由延后量现算，越界延后量或多余交接判为损坏档。
- 沿用SaveRepository事务、失败重试和损坏档保护。单独临时测试档不接触玩家进度。

## 场景与后续

保留已认可的错拍码头背景、吊台、小车与直通轨源图。新班次时刻表铺在码头上，从第0拍排到第16拍；小车到点、吊台整条时刻表随延后量平移、两次交接判定由引擎绘制。手动逐档停顿便于比较，失焦和模态暂停表现。

嗒嗒亲自按住启动杆，两托货赶在开船前送出去，旧灯轴真正出海，随后通过玩家对话加入。只完成GW04，不扩展GW05、跨岛解锁或伙伴加入。

## 验证

规则测试独立枚举3档延后量 × 两次交接的候选，用独立标量计算验证唯一解（延后2拍、交接4和16）以及每档的相遇记录与整单完成判定。窗口测试覆盖1280×720、960×540的输入、错误试运行、三档比较、光标移动、撤销、保存失败重试、重载、发现卡及损坏档保护。实际命令与候选身份见 `docs/playtest/workshop-gw04/verification.json`。

这些检查证明规则与交互实现；小学三年级学生的实际挑战感、理解和学习效果仍须真人试玩。
