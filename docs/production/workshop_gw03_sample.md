# GW03 · 相遇了，还不能交接

2026-09-24。按 [GW01契约](workshop_gw01_sample.md) 同一套三年级奥数难度与制作原则实现。核心思考是「列表找重合、筛选」：先把两条机轨的相遇时刻列出来，再逐个去查放行灯。不是原章节里的基础分组轻关，也不声称已通过儿童难度实测。

## 可玩契约

吊台第2拍首次到达，以后每3拍一次；小车第3拍首次到达，以后每4拍一次；放行灯第3拍首次亮，以后每5拍亮一次。每次到达或亮灯只持续该时刻，不能停留等候。只有两机同时到达且灯同时亮，才可交接。求1～40拍中第一次合法交接。

吊台与小车同时出现在11、23、35拍；放行灯只在3、8、13、18、23…亮。逐一核对，只有第23拍三者同时成立，所以首次合法交接是23。11拍上两机确实碰头，可灯没亮——不能把周期相乘直接当答案，也不能因为两条规则成立就当成三条一起成立。

- 三条节拍表与「看过哪几拍」全部由规则模块现算，画面不另存事件表，改拍号不会留下旧标记。
- 到达格只有在玩家真的运行过那一拍之后才点亮，画面不预先摊开整张时刻表。
- 四档主动提示依次为：两机共同时刻 → 这些时刻的灯 → 11拍灯亮吗 → 首次23拍。默认不显示解，也不要求手工点满40格。

玩家可在三条节拍带上标记自己的预测，指定试验时刻；运行只展示选定时刻附近的实际事件（该拍及前后各两拍），也可逐拍回看。通过须把拍号定为最早合法时刻，主动确认才进入剧情。

## 操作与存档

- 启动 `启动齿轮工坊GW03样板.command` 或 `game/workshop_gw03.tscn`。
- 鼠标完整可玩；点节拍带任意一格就是运行那一拍，←/A上一拍、→/D下一拍，R运行此拍，Z撤销，X确认重查，H主动提示，Space定为交接点。保留Tab/Enter焦点操作。
- 41格逐个点太碎，所以三条带各挂一个整条热区，点哪一格由横坐标算出来。
- 新独立存档 `user://profiles/workshop-gw03-1/save-v1.json`，不读写、不删改其它关卡档案。持久化光标拍号、看过的拍号集合、阶段、对白停点、提示级别；三条节拍表由规则现算，越界拍号判为损坏档。
- 沿用SaveRepository事务、失败重试和损坏档保护。单独临时测试档不接触玩家进度。

## 场景与后续

保留已认可的错拍码头背景与吊台、小车、铃灯源图。三条节拍带（吊台/小车/放行灯）横贯画面，从第0拍到第40拍逐格对齐；到达点、探针与交接判定由引擎绘制。交付那一幕吊台落到小车上方，正好停在真正同时的第23拍上。失焦和模态暂停表现。

第一托货完成交接；余下两托转入下一班船，新班次从第0拍重新计时，期限更紧，引出GW04的调起点。只完成GW03，不扩展跨岛解锁或伙伴加入。

## 验证

规则测试独立枚举1～40拍的全部时刻，用独立取模判定验证唯一解第23拍，并核对两机相遇的11、23、35拍与灯的亮拍集合。窗口测试覆盖1280×720、960×540的输入、错误交接、逐拍回看、指定试验时刻、撤销、保存失败重试、重载、发现卡及损坏档保护。实际命令与候选身份见 `docs/playtest/workshop-gw03/verification.json`。

这些检查证明规则与交互实现；小学三年级学生的实际挑战感、理解和学习效果仍须真人试玩。
