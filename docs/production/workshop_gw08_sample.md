# GW08 · 两张旧单，锁定一块槽板

2026-09-25。按 [GW01契约](workshop_gw01_sample.md) 同一套三年级奥数难度与制作原则实现。核心思考是「余数还原、交叉排除」：每张记录先各自还原出满托总数与候选，两张合起来才只剩一个。不是原章节里的基础余数题，也不声称已通过儿童难度实测。

## 可玩契约

同型旧托盘每托装 5～16 根整数灯轴。记录一：35 根装完满托后剩 3 根；记录二：47 根装完满托后剩 7 根。没有损耗，余下数量必须小于每托容量。

补掉余数后，32 与 40 必须都能整分：记录一允许 8、16；记录二允许 8、10；交集只有 8。只看任一记录都不能确定，也不能把「可被整除」与「合法余数」分开忽略。

- 候选槽数、两张记录的重演结果与排除表全部由规则模块现算，画面不另存除法结果，换槽数不会留下旧判定。
- 每张记录必须真的重演过（按当前候选跑一遍除法）；余数对不上时念出真实余数，两张都重演且都相符才能提交。
- 四档主动提示依次为：先去掉零散数 → 32 与 40 要能同时整分 → 两份候选分别是 8、16 与 8、10 → 只有 8。默认不显示解。

## 操作与存档

- 启动 `启动齿轮工坊GW08样板.command` 或 `game/workshop_gw08.tscn`。
- 鼠标完整可玩；点 5～16 的候选牌提出槽数，点「重演记录一 / 二」分别重演，←/A 与 →/D 移动候选，R 重演记录一、T 重演记录二，Z 撤销，X 确认重摆，H 主动提示，Space 定为槽数。保留 Tab/Enter 焦点操作。
- 新独立存档 `user://profiles/workshop-gw08-1/save-v1.json`，不读写、不删改其它关卡档案。持久化候选槽数、两张记录的重演表、阶段、对白停点、提示级别；越界槽数与重复、越界的重演记录判为损坏档。
- 沿用 SaveRepository 事务、失败重试和损坏档保护。单独临时测试档不接触玩家进度。

## 场景与后续

沿用已认可的装配间背景与槽盘、灯轴、嗒嗒母版。两张维修记录并排，各挂「重演」按钮；重演后按当前候选把满托排开、零散灯轴留在旁边，余数相符标绿、不符标红。旧槽板、候选牌与判定由引擎绘制。失焦和模态暂停表现。

容量牌补上后，旧报时廊的灯等着换，引出 GW09 的循环步长与旧灯号记录。只完成 GW08，不扩展跨岛解锁或伙伴加入。
