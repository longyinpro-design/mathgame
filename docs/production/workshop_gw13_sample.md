# GW13 · 两只鸟，到底叫了几次

2026-09-25。按 [GW01契约](workshop_gw01_sample.md) 同一套三年级奥数难度与制作原则实现。核心思考是「重叠计数、端点不漏」：两只鸟各自的叫点加起来会把同拍的部分数两遍，必须先把重合挑出来，再把总时刻与独鸣分开数。GW13 是 GW04 之后的可选支线，不挡主线解锁，也不声称已通过儿童难度实测。

## 可玩契约

两只玩具鸟第 0 拍一起叫，此后甲每 4 拍叫一次、乙每 6 拍叫一次；观察 0 到 24 拍，两端都算。同一拍两只一起叫，只算一个「听到叫声的时刻」。

甲叫 7 次（0、4、8、12、16、20、24），乙叫 5 次（0、6、12、18、24），0、12、24 三拍重合：不同时刻 7+5−3=9，独鸣 9−3=6（4、6、8、16、18、20）。

- 叫点表、重合表、独鸣表与两个数量的判定全部由规则模块现算，画面不另存叫点，改标记不会留下旧判定。
- 玩家先在时间尺上圈出认为重合的时刻（圈上的集合必须正好是 0、12、24），再提交两个数量；三个子答案同时成立才能提交，提交被拒时只念出最要紧的一处真实原因。
- 反例逐条对上：漏掉第 0 拍只剩 8 个时刻；把 7+5=12 当成总时刻会把三拍重合数两遍；独鸣只从一只鸟的次数里扣会得到 4 或 2。
- 两个数量各用 0～12 的候选牌：两只鸟一共 12 次叫声，听到的时刻与独鸣都不可能超过 12，候选上界本身不透露答案。
- 四档主动提示依次为：同拍只算一个时刻 → 先圈重合 → 区分总时刻与独鸣 → 9 与 6 及完整列表。默认不显示解。

## 操作与存档

- 启动 `启动齿轮工坊GW13样板.command` 或 `game/workshop_gw13.tscn`。
- 鼠标完整可玩；点时间尺上的一列圈出 / 取消重合，点两行 0～12 的候选牌提交两个数量，←/A 与 →/D 移动时间尺上的拍标，M 圈当前拍，↑/↓ 换数量行，Q/E 改当前数量，Z 撤销，X 确认重摆，H 主动提示，Space 提交。保留 Tab/Enter 焦点操作。
- 新独立存档 `user://profiles/workshop-gw13-1/save-v1.json`，不读写、不删改其它关卡档案。持久化圈过的拍、两个数量、阶段、对白停点、提示级别；越界的拍、重复的圈、越界的数量与旧版本号判为损坏档。
- 沿用 SaveRepository 事务、失败重试和损坏档保护。单独临时测试档不接触玩家进度。

## 场景与后续

沿用已认可的装配间背景与槽盘、嗒嗒邀请母版。0～24 的时间尺横贯画面，甲、乙两条叫点带逐拍对齐；圈出的重合用金圈套住整列，两只鸟蹲在右侧的休息桌上，拍标指到哪一拍、正在叫的那只会张开嘴。两个数量的候选牌由按钮绘制，判定条与「叫点记录」由引擎绘制。走位那一格休息桌与两只鸟从左边推进来；失焦和模态暂停表现。

关卡标题「齿轮工坊 · 两只鸟，到底叫了几次」比 GW12 的显示名还短一个汉字，按 22 号字在顶栏牌子约 382px 的内框里排得下一行，实窗检查里标题与目标行都不折行，因此场景内沿用目录全名，不做 GW12 那样的缩短。

GW13 是 GW04 之后的可选支线：办完不影响主线解锁，只留下「重复的部分要分清」的发现卡，小鸟留在休息桌保留人物支线气氛。GW14 的第三张记录、GW15 的最早观察、GW16 的午休曲各自从自己的前置开门。只完成 GW13，不扩展跨岛解锁或伙伴加入。

## 验证

规则测试用最笨的枚举独立生成两只鸟的叫点、并集、交集与对称差，验证甲 7 次、乙 5 次、重合 0、12、24、不同时刻 9、独鸣 6，并逐拍对照全部 25 拍；另核对两个数量的候选范围、三个子答案的逐格判定、提交守卫、撤销与重摆、伪造标记／数量／阶段、旧版本号与存档事务（open／flush／replace 失败注入、坏档保护与备份）。窗口测试覆盖 1280×720、960×540 的输入、圈错拍与两个反例被拒、撤销、重摆、键盘与按钮同一条判据、提示与保存失败重试、提交失败重试只进一次、重载续档、发现卡与损坏档保护。

验收命令为 `Godot --headless --path . --script tests/workshop/gw13_test.gd`（摘要 `GW13 RULES: 348 checks, 0 failures`）与 `Godot --path . --script tests/workshop/gw13_playtest.gd`（摘要 `GW13 WINDOW: 455 checks, 0 failures`）；两轮的实窗截图见 `docs/playtest/workshop-gw13/`。`tests/workshop/run_checks.py` 的关卡清单尚未收录 GW13，本关因此没有该脚本生成的 `verification.json`。

这些检查证明规则与交互实现；小学三年级学生的实际挑战感、理解和学习效果仍须真人试玩。
