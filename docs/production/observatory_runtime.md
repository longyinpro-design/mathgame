# 星穹观测台：18关运行说明

本章在Godot 4.6.3下实现，采用共享群岛会话。定义 → 纯规则 → 事务会话 → 操作/绘制分离。没有网络、在线模型、独立奖励写盘或数字答案输入框。

## 制作与文件

- `scripts/observatory/levels.json`：18个完整作者定义、可见约束、手动前后对白、独立奖励、主支线依赖
- `catalog.gd`：只读深拷贝；JSON整数规范化
- `rules.gd`：闭合状态与动作schema、纯函数、新状态、不修改输入、按约束裁定所有合法解
- `level_scene.gd`：共享Control宿主的真实控件和点击热区
- `world.gd`：黄铜穹顶、星图台、实体百叶、线缆与发射轨、望远镜、角色；场景读实际状态，禁止写完成事实
- `game/observatory_so01.tscn`至`so18.tscn`：18个入口

## 关卡不是参数换皮

| ID | 现场与玩家动作 | 核心约束 |
|---|---|---|
| SO01 | 拿三枚星点装到放大星盘 | 原点不变，横纵2倍 |
| SO02 | 把观测基点搬到新台 | 分别从旧、新基点量，缩放并平移 |
| SO03 | 制作口袋星图 | 固定格尺，横纵缩小一半 |
| SO04 | 开晨光百叶 | 整体20格，25%开放 |
| SO05 | 调不同大小的双窗 | 12格与20格各50%，整体不可混用 |
| SO06 | 风后调完好镜片 | 原16格坏4格，本次整体是余下12格 |
| SO07 | 连接两镜观测顺序并收藏 | 3选2有序，共6路，反序不同 |
| SO08 | 避免红蓝连续串光 | 4选3有序，邻接禁配，完整16路 |
| SO09 | 从台到港接中继线 | 单向边，无重复站，全部3路 |
| SO10 | 三封信排单泊位发射 | 释放、截止、轨道不重叠 |
| SO11 | 两轨交叉调度 | 轨道选择和时刻，同时经过交叉点也冲突 |
| SO12 | 在快慢轨间分配补给 | 每船不同航时/能耗，期限内最低4晶 |
| SO13 支线 | 离轴风筝星图 | 平移不改变大小，检验基点概念 |
| SO14 支线 | 脆弱百叶少改动 | 整窗40%、4亮格连续，与初态最少5格不同 |
| SO15 支线 | 灯塔限定目录 | 单向路径必须经过指定中间站，全部3路 |
| SO16 支线 | 最紧凑夜班 | 两轨总8时工作量，最短4时完成 |
| SO17 首领 | 抗风布线→真实切断→重接 | 初态任断1边仍通；确定性切最小编号已装线；最多1新边，≤10晶，任意两塔≤2跳 |
| SO18 终章 | 六岛布线与联合发船 | ≤8晶接通六岛，实际最短航程决定占道时长，6船不重叠且22时前到港 |

13–16没有进入17或18的主线先修。首领17与18采用不同的多约束玩法：17保存合法抗風证书与真实断线分支；18用玩家亲手建设的网络决定排班约束，不能用独立算术数值替代路线。

## 表现与操作

全部棋盘保持在共享宿主保留区内。星点先选后落，百叶直接开闭，路线逐点接线后收藏，货船先选后放入时格，网络点击带“费/时”标签的物理线缆开关。文字始终说明整体、单位、时刻与预算。共享层处理提示、撤销、重摆、暂停、保存失败、首通奖励与故事推进。

终章联合试航按当前边集计算最短路径，按真实出发时刻推进六船位置；纯视图时钟受`presentation_paused`控制，不改变规则或奖励。每条边航时是作者参数，不把费用当作航程。解后灯束来自实际`solved`重新计算。

## 独立证据与限制

`tests/observatory/oracle.py`不加载GDScript规则，分别使用格点枚举、组合枚举、排列枚举、排班穷举、Floyd最短路与子集网络枚举。证明全部18可解；验证两项最优值、7个最少改动百叶解、3个守望者合法初局均有修复、165个可排班的六岛网络。生成的`witnesses.json`仅供测试，不进作者定义或运行答案逻辑。

`test_rules.gd`通过纯动作完成18关及替代解，检查输入不变、未知字段/动作拒绝、JSON往返与提示。`test_adversarial.gd`检查非有限数、布尔值/小数坐标、重复格/点、破损百叶、伪造首领阶段、冲突排班与终章断网/超预算。

`test_ui.gd`注入真正鼠标按下/抬起事件，通过实际按钮/热区完成全部18关，两种窗口尺寸各一次，并经共享Repository重新读取保存棋盘、真实提交与领奖。可在headless验证输入/事务，但只有native运行产出截图；截图不代表儿童真人体验结论。两尺寸native共36关次已通过并生成24张截图，详情见`docs/playtest/observatory/verification.md`。

不宣称Godot4.7、macOS、儿童试玩或触屏验收。整体旅程和旧三岛接续由群岛集成层验证。
