## 可见变化

- 角色站在共享木台、石台或实际吊篮里。步态按位移推进、停止移动即停步；伙伴各自跟随。站长静止时不再循环误用蹲下帧。
- 运输先提交真实结果，画面仍把人留在正在升降的篮里，到站后再移上站台。剧情复用实际货物位置；第一幕不再出现两套重复演员。
- 信封有包裹、站长、小岚三阶段归属，画面中的手会接触信封；拆信保留实物与下方可读正文。旧档无运输明细时只展示标明的回顾，不伪造已完成装载现场。
- 三门有石基、支脚和连接光道；苔团加入后保留实际 FL02 最终结果。村庄灯、磨坊育苗和邮路旗号按已有完成事实显示。
- FL07 把四张数字牌放进实体机台牌架和两个卡槽，齿轮、表盘与组合状态相连；剧情使用同一个机关组件。保持 1/4/5/9、完整表达式、负数/分数、撤销及原判定。
- 各类板面有工作台承托，路线有地面模型和木质路段，战斗演员有地面；树根成桥后队伍再通过，暂停/跳过移到右上方；结尾按已完成事实回看地区。
