## 视觉改动

- 复用原图三仓木门、台阶与石路；本样板无新增整宽地面、虚构仓房或巨型仓牌。原背景 `village-v1.png` 未编辑。
- 门上数量签、透明仓门热区、小岚推粮车、同伴朝向与脚下接触阴影共同表达现场操作。移动仍按真实路程播放步态。
- 粮车携带数从送出仓可见数量扣除；行驶时三仓与车上粮袋总数保持30。到站后的结果、时间回看和剧情跳过均由真实收据驱动。
- 剧情与关卡使用同一村庄坐标系；对白/控制移到原路面下方。成功横幅与相等报告在搬运结束后出现。
