# 「连线」两关重设计 — FL08 / FL10（2026-09-17）

## 问题

用户反馈：走格子的两关想通之后只剩重复劳动。

- FL08 要手画全部 10 条路线并逐条归袋（约 63 次点击），绕路的解法完全一样。
- FL10 要枚举全部 6 组配对（约 72 次点击），且"为什么只有 6 组"并没有被问到。

## 重设计

### FL08 不会漏信的分邮袋 → 复核折羽的邮袋

折羽已按"第一次向右的高度"归档，但**一条放错袋**（URURR 进了 0 层，实际第 1 层）、**一条没归档**（RUURR）。

玩家要做三件事：
1. 用规则找出放错的那张（它的第一次向右层数与所在袋不一致）→ 点"移正"；
2. 写出三层应有的条数 **6 / 3 / 1**（即 C(4,2)、C(3,2)、C(2,2)）——这正是发现少一条的依据；
3. 把缺的那条画出来补进袋子。

交互约 8 次；推理链是"套规则 → 用组合数校验完整性 → 补出遗漏"。

### FL10 互不碰面的两封信 → 同时出发的信 + 上限论证

不再枚举配对，改为：
1. 从 10 条走法里挑出一组能同时出发、中途不碰面的（唯一可行形态：一右一上，如 RRRUU + URRUR）；
2. 选对"为什么放不下第三封"的理由——抽屉原理：**先向右的信都经过 (1,0)，先向上的都经过 (0,1)，三封里必有两封同向，一定在中途相撞**。

交互约 5 次；保留了"各自合法 ≠ 能同行"的原洞察，并新增上限证明。

## 不变的数学

| 项 | 值 |
| --- | --- |
| 路线总数 | 10 |
| 分袋 | 6 / 3 / 1（组合数 C(4,2)/C(3,2)/C(2,2)） |
| 可配对总数 | 6 |
| 同时出发最大封数 | 2 |
| 首通奖励 | 不变 |
