# FL07 可玩性修复

用户现场：正式剧情停点 `puzzle_FL07`，外部输入与多次观察已保存，装配栏里还留着 `double/plus3/minus1`。只读核对玩家存档，未将其用于测试写入。

复现：真实Godot窗口用独立临时档重建同一类局面，实际点击外部试验、不同内部记录和两种最终装法。旧版38条检查28通过、10失败：原机实际观察值未常驻，外部结果被后续提示替换，无关装配/启动按钮混入最终推断，错误选择没有数字对照，重开后依旧找不到关键记录。旧截图和日志为 `before.png`、`before.log`。

修复：独立的两种候选对照布局；已查看的中间值和原机记录常驻，额外外部试验保留结果；本关移除无关模块装配/启动入口；扩大数值输入区域；错误结论直接比较预测与原机记录；显示模块名称使用中文，存档key保持原英文ID。数学参数、完成条件、已存观察与玩家进度不变。

自审：bounded的界面与反馈改动；检查精确diff、原存档标识、旧字段兼容和FL05共用绘制分支。没有新增代理或更改全局配置。

验证：`fl07_playtest.gd` 使用1280×720和960×540真实视口输入，检查数值输入无重叠、加减、不可区分记录不提前作结论、错误选择、重开保持可见证据、正确完成以及中文显示名不改变存档key。新增窗口检查51/51 PASS；项目完整22项2534/2534 PASS、source_stable=true。完整结果与候选SHA256见 `verification.json`。本项不把通过测试替代儿童理解难度的真人验证。

供用户观看的修复窗口使用 `.scratch/fl07-preview/save.json` 独立副本；原窗口未强制关闭，原存档未重置。正式入口重开后即可加载新代码并继续原进度。
