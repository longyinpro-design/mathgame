## 窗口测试运行器修订

本机外部应用焦点切换会正常触发游戏取消拾取/行走。测试专用 helper 使用可见原生 NO_FOCUS 窗口；首次输入前通过文件握手，由 runner 恢复测试启动前已读取的前台进程，等待测试窗口确实失焦后继续。输入仍进入真实视口 Control；生产失焦逻辑和显式失焦/后台控件断言保持不变。这不等于实际 OS 切换焦点的人工作业验收。

独立轻量复核发现 runner 超时后可能遗留子进程的P2，已修复为 terminate、等待回收、必要时 kill 并回收；前台恢复和测试执行超时均明确失败，finally 完成清理后才继续下一项。主会话用真实普通 sleep 与忽略 SIGTERM 的 Python 子进程验证 -15/-9 返回且已回收，reviewer 定向复核关闭。
